Media Batch Downloader 使用說明
==============================

這是一個批次媒體下載工具，支援：
- Instagram
- Facebook

目前主要流程：
1. 匯入原始 txt
2. 自動預處理分類
3. 自動載入可下載連結
4. 開始下載

--------------------------------
一、最簡單使用方式
--------------------------------

方法 A：直接匯入 txt（推薦）
--------------------------------
1. 開啟 Media Batch Downloader
2. 點「📂 匯入 txt（自動預處理）」
3. 選擇你的原始 txt 檔案
4. 程式會自動：
   - 抽出網址
   - 分流成可下載 / 不可下載
   - 自動載入可下載清單到輸入框
5. 點「🚀 開始下載」

方法 B：手動貼 URL
--------------------------------
1. 直接把網址貼進輸入框
2. 每行一個，或混雜文字也可以
3. 點「🚀 開始下載」

--------------------------------
二、pre-processing 整合流程
--------------------------------

如果你的原始資料像這樣：

9:15 aaa https://www.instagram.com/reel/xxxx
1:04 bbb https://www.instagram.com/p/yyyy
9:30 ccc https://www.facebook.com/share/xxxxxxxxxx/

這種混雜：
- 時間
- 人名
- 描述文字
- URL

建議直接使用：
「📂 匯入 txt（自動預處理）」

程式會呼叫：
pre-processing/link_sorter.py

並自動產生：
- pre-processing/output/download_link.txt
- pre-processing/output/undownload_link.txt

其中：
- download_link.txt = 可下載連結
- undownload_link.txt = 不可下載或非媒體連結

--------------------------------
三、支援的連結類型
--------------------------------

Instagram：
- /p/
- /reel/
- /reels/

Facebook：
- /share/
- /share/r/
- /share/v/
- /watch/
- /reel/
- /videos/
- /posts/
- /story.php
- fb.watch/

注意：
Facebook 的 share 連結現在也會視為可下載連結。

--------------------------------
四、按鈕說明
--------------------------------

🚀 開始下載
開始處理目前輸入框裡的 URL

🧹 清空輸入框
清掉輸入框內容，不影響已下載檔案

📂 匯入 txt（自動預處理）
匯入 txt，若內容不是純 URL 清單，會自動先做預處理分類

🧩 預處理分類
手動執行 pre-processing/link_sorter.py

📥 載入可下載清單
把 pre-processing/output/download_link.txt 載入輸入框

📁 開啟下載資料夾
直接打開 downloads 資料夾

🔑 登入 IG
手動登入 Instagram 帳號

📄 查看失敗
彈出視窗顯示目前 FAILED / BLOCKED / RETRY / UNAVAILABLE 的連結與原因

⏸ 暫停
暫停下載流程

▶ 繼續
繼續已暫停的下載流程

⏹ 停止
停止下載流程
注意：
- 正在下載中的那一筆不一定會立刻中斷
- 會等目前任務安全收尾後停止

🔁 重試失敗
把 FAILED / BLOCKED / RETRY 的任務重新丟回下載佇列

🗑 清空任務
清空任務列表

注意：
- 不會刪除已下載檔案
- 會先把失敗與無法下載的連結寫入 log

--------------------------------
五、任務狀態說明
--------------------------------

PENDING
等待下載

DOWNLOADING
下載中

SUCCESS
成功下載

FAILED
下載失敗
通常是：
- 網址格式有問題
- 平台回傳異常
- 暫時抓不到檔案

BLOCKED
被平台限制
常見原因：
- IG / FB 需要登入
- 年齡限制
- 帳號受限
- 僅特定對象可觀看

UNAVAILABLE
內容已刪除、失效、404、頁面不存在

RETRY
暫時失敗，後續可重試

--------------------------------
六、進度條與冷卻
--------------------------------

程式會顯示：
- 進度：已完成 / 總數
- 目前狀態：下載中 / 冷卻中 / 等待任務 / 已暫停 / 已停止
- 目前 URL
- 冷卻倒數秒數

說明：
平台（特別是 Instagram / Facebook）容易限制請求速度，
所以每次成功下載後，程式會自動冷卻幾秒鐘，
這是正常行為，不是卡住。

--------------------------------
七、Instagram 登入與 cookies 說明
--------------------------------

建議優先順序：

1. 使用 cookies.txt（最穩）
2. 使用 accounts.json 登入
3. 帳密 + 2FA 只作為補充方案

如果 IG 內容出現：
- 年齡限制
- 僅特定對象可看
- 未登入無法觀看

那麼即使程式正常，也可能只能顯示 BLOCKED。

重要：
如果你已用同一個帳號在瀏覽器確認過可以看到內容，但程式仍失敗，
通常代表：
- cookies.txt 不是最新
- cookies.txt 匯出不完整
- 程式目前實際載入的 cookies 不是你以為的那份
- 瀏覽器的登入狀態與程式請求狀態仍有差異

也就是：
「瀏覽器可看」不一定等於「程式目前這份 cookies 一定可抓」。

--------------------------------
八、Facebook 下載說明
--------------------------------

Facebook 下載原則和 Instagram 類似：

1. 若是公開內容，通常可直接下載
2. 若是 share 連結，現在也會被納入可下載清單
3. 若內容需要登入或受限，也可能顯示 BLOCKED
4. 若內容已刪除或不存在，則顯示 UNAVAILABLE

--------------------------------
九、檔案輸出位置
--------------------------------

下載完成的檔案會放在：

downloads\

單檔命名：
downloads\標題.mp4
downloads\標題.jpg

多檔貼文命名：
downloads\標題\1.jpg
downloads\標題\2.mp4

Instagram 與 Facebook 都統一走：
- 先下載到 temp
- 再搬到 downloads
- 最後套用同一套命名規則

--------------------------------
十、命名規則
--------------------------------

檔名會自動清理：

1. 簡體轉繁體
2. 一二 -> Bubu
3. 布布 -> Dudu
4. 移除 Windows 非法字元
5. 去掉不可見字元
6. 長度限制 60 字
7. 空標題用 Untitled

--------------------------------
十一、斷點與避免重複下載
--------------------------------

程式會使用：

data\processed_links.log

紀錄已成功下載的連結。

同一個連結若已成功下載過，
之後再次加入任務時會自動略過，不會重複下載。

--------------------------------
十二、失敗紀錄
--------------------------------

失敗紀錄會寫到：

data\retry_needed.txt
data\unavailable_links.txt
data\failed_links.log

格式包含：
- 執行時間戳
- URL
- 失敗原因

說明：
- retry_needed.txt：適合之後重試的連結
- unavailable_links.txt：失效或受限連結
- failed_links.log：所有失敗事件的完整紀錄

--------------------------------
十三、建議使用流程
--------------------------------

推薦日常流程：

1. 把原始分享內容存成 txt
2. 開啟 Media Batch Downloader
3. 點「📂 匯入 txt（自動預處理）」
4. 點「🚀 開始下載」
5. 若有 BLOCKED：
   - 先更新 cookies.txt
   - 再點「🔁 重試失敗」
6. 若要查看失敗細節：
   - 點「📄 查看失敗」

--------------------------------
十四、常見問題
--------------------------------

Q1. 為什麼會顯示 BLOCKED？
A:
代表平台限制，不一定是程式壞掉。
例如：
- 需要登入
- 年齡限制
- 內容只對部分帳號可見

Q2. 為什麼成功後還要等？
A:
這是冷卻時間，避免平台封鎖。

Q3. 匯入 txt 一定要先整理格式嗎？
A:
不用。
現在「📂 匯入 txt（自動預處理）」會自動判斷並處理。

Q4. 清空任務會刪掉下載檔嗎？
A:
不會，只會清空任務列表。

Q5. 2FA 驗證碼正確卻登入失敗？
A:
IG 的驗證挑戰有時不穩定。
建議優先使用 cookies.txt。

Q6. Facebook share 連結能下載嗎？
A:
可以。
現在像 facebook.com/share/... 這類連結會先被判定為可下載，再交給下載器處理。

Q7. 我已經有 cookie，為什麼還是失敗？
A:
因為 cookie 只代表某個登入身分。
如果該帳號本身沒有權限、cookie 已過期、或匯出不完整，仍然會失敗。
